================================================================================
RESUMEN DE MÓDULOS Y TECNOLOGÍAS
================================================================================

Backend (FastAPI + Python):
- Framework: FastAPI 0.109+
- Base de datos: PostgreSQL 15+ con SQLAlchemy 2.0
- Autenticación: JWT con python-jose
- OCR: Tesseract OCR
- Exportación: ReportLab (PDF), OpenPyXL (Excel)
- Testing: pytest
- Total endpoints: ~50 endpoints REST
- Total modelos: 14 tablas en base de datos

Frontend (Next.js + React):
- Framework: Next.js 14 (App Router)
- UI: React 18 con TypeScript
- Estilos: TailwindCSS
- Gráficos: Chart.js
- Formularios: React Hook Form + Zod
- HTTP Client: Axios + SWR
- Total páginas: ~40 páginas

Base de Datos (PostgreSQL):
- 14 tablas relacionales
- Integridad referencial completa
- Índices optimizados
- Triggers para timestamps automáticos
- Soporte para transacciones ACID

Funcionalidades Principales:
✓ Gestión de usuarios con roles
✓ CRUD completo de clientes y proveedores
✓ Gestión de productos e inventario
✓ Registro de compras y ventas
✓ Procesamiento de facturas con OCR
✓ Control de ingresos y egresos
✓ Dashboard con métricas y gráficos
✓ Generación y exportación de reportes
✓ Autenticación y autorización
